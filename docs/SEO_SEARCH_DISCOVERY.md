# Burner Point SEO, Indexing, and Search Discovery

Date: 2026-04-17

This document covers the production search-discovery setup for Burner Point across sitemap, robots, Open Graph, structured data, Google Search Console, Bing Webmaster Tools, and IndexNow.

## Implemented Web Routes

| Route | Purpose |
| --- | --- |
| `/sitemap.xml` | Public XML sitemap generated by Next.js from the canonical public route registry |
| `/robots.txt` | Crawl rules that allow marketing pages and block auth, dashboard, onboarding, callbacks, tests, and internal API paths |
| `/opengraph-image` | Dynamic 1200x630 social share image |
| `/twitter-image` | Twitter/X share image using the same branded social preview |
| `/indexnow-key.txt` | IndexNow key location when `INDEXNOW_KEY` is configured |
| `/manifest.webmanifest` | PWA/app metadata for install and social surfaces |

## Metadata Coverage

The web app centralizes SEO in `apps/web/src/lib/seo.ts`.

Every public page receives:

- `title`
- `description`
- canonical URL
- `og:title`
- `og:description`
- `og:image`
- `og:url`
- Twitter/X large image metadata
- search robots metadata
- shared keywords

Private and authenticated routes are protected with `X-Robots-Tag: noindex, nofollow, noarchive` through `apps/web/next.config.js`.

## Structured Data

The root layout emits:

- `Organization`
- `WebSite`
- `SoftwareApplication`

Public content pages emit relevant structured data:

- `WebPage`
- `BreadcrumbList`
- `FAQPage` for FAQ pages
- `Article` entries for blog sections
- `ContactPage` for contact/support pages
- `ItemList` for homepage product modules

## Google Search Console Setup

1. Open Google Search Console.
2. Add the production domain property for Burner Point.
3. Choose HTML meta tag verification.
4. Copy the verification token only, not the full tag.
5. Set `GOOGLE_SITE_VERIFICATION` in Vercel production and preview environments.
6. Redeploy the web app.
7. Confirm the homepage contains the verification meta tag.
8. Submit `https://YOUR_PRODUCTION_DOMAIN/sitemap.xml`.
9. Inspect the homepage, pricing page, verifications page, rentals page, blog page, FAQ page, and contact page.
10. Request indexing after the production domain is stable.

## Bing Webmaster Tools Setup

1. Open Bing Webmaster Tools.
2. Add the production domain.
3. Choose meta tag verification.
4. Copy the `msvalidate.01` token only.
5. Set `BING_SITE_VERIFICATION` in Vercel production and preview environments.
6. Redeploy the web app.
7. Submit `https://YOUR_PRODUCTION_DOMAIN/sitemap.xml`.
8. Enable IndexNow if the Bing project asks for it.

## IndexNow Setup

IndexNow is appropriate for Burner Point because the product has updates, blog content, pricing, help content, and public product pages that should be discoverable quickly after launch changes.

1. Generate a random IndexNow key.
2. Set `INDEXNOW_KEY` in both Vercel web env and Railway API env.
3. Confirm `https://YOUR_PRODUCTION_DOMAIN/indexnow-key.txt` returns the key.
4. Confirm the API has `WEB_URL=https://YOUR_PRODUCTION_DOMAIN`.
5. Use the admin endpoint `POST /api/admin/indexnow/ping` with a body such as:

```json
{
  "urls": [
    "https://YOUR_PRODUCTION_DOMAIN/",
    "https://YOUR_PRODUCTION_DOMAIN/pricing",
    "https://YOUR_PRODUCTION_DOMAIN/verifications",
    "https://YOUR_PRODUCTION_DOMAIN/rentals",
    "https://YOUR_PRODUCTION_DOMAIN/blog"
  ]
}
```

The API will skip IndexNow automatically when `INDEXNOW_KEY` is missing.

## Social Share Optimization

Use these checks before launch:

- Homepage share preview uses `/opengraph-image`.
- Public pages include absolute `og:url`.
- Public pages include `summary_large_image` Twitter/X cards.
- Image dimensions are 1200x630.
- The image uses Burner Point dark green, black, cyber green, and metallic styling.
- Social URLs resolve with 200 status.
- Canonical URLs use the final production domain, not a Vercel preview URL.

## Launch Checklist

1. Set `NEXT_PUBLIC_APP_URL` to the production domain in Vercel.
2. Set `WEB_URL` to the production domain in Railway.
3. Set `GOOGLE_SITE_VERIFICATION`.
4. Set `BING_SITE_VERIFICATION`.
5. Set `INDEXNOW_KEY`.
6. Run `npm run build` in `apps/web`.
7. Open `/sitemap.xml` and confirm every public route is present.
8. Open `/robots.txt` and confirm private routes are blocked.
9. Open `/opengraph-image` and confirm the branded card renders.
10. Open `/indexnow-key.txt` and confirm it returns the key only in production.
11. Submit the sitemap in Google Search Console.
12. Submit the sitemap in Bing Webmaster Tools.
13. Trigger IndexNow after launch.
14. Test social previews for `/`, `/pricing`, `/verifications`, `/rentals`, `/blog`, `/faq`, `/help`, and `/contact`.
15. Confirm `/dashboard`, `/auth/login`, `/auth/signup`, `/onboarding`, `/sso-callback`, and `/test` do not index.
16. Confirm Terms and Privacy Policy resolve from footer links.
17. Confirm support URLs resolve: `/support`, `/help`, `/contact`, `mailto:info@burnerpoint.com`, and Telegram links.
