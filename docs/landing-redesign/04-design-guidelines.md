# Burner Point Design Guidelines

## Brand constants
- Deep Green: `#013220`
- Cyber Green: `#00FF9D`
- Neon Green: `#39FF14`
- Black: `#000000`
- Metallic gradient: `#9FA6B2 -> #E5E7EB`

## Visual system
- Dark premium background
- Strong typography hierarchy
- Metallic text accents
- Soft glass surfaces, not cheap OTP-site visuals
- Green glow used selectively for hierarchy, not everywhere

## Copy rules
- Use: private number, supported verification, renewable rental, secure connectivity.
- Avoid: bypass, guaranteed everywhere, unlimited account creation, undetectable.
- Keep trust/safety language explicit.
