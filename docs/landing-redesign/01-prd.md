# Burner Point Marketing Redesign PRD

## Goal
Ship a new Burner Point public web experience that positions the company as a privacy-first communication and connectivity platform instead of a single-purpose second-number app.

## Primary outcomes
- Reframe Burner Point around six products: Messenger, Verify Hub, Rentals, eSIM Store, Proxy Store, Secure Tunnel.
- Replace the current homepage with a premium, dark, brand-consistent landing page.
- Align auth entry screens with the new marketing system.
- Add a dedicated FAQ page with product categories and support context.

## In scope
- Homepage IA, copy, visuals, CTA structure, FAQ preview, trust/safety messaging.
- Shared marketing header/footer.
- Login and signup visual redesign without changing Clerk business logic.
- FAQ route and SEO.

## Out of scope
- Dashboard redesign.
- Backend schema changes.
- Payment gateway implementation changes.
- New API endpoints.
